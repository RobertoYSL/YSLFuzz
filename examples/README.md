# Examples

This directory contains local inputs for YSLFuzz documentation and tests.

- `openapi/`: REST/OpenAPI example schemas.
- `graphql/`: GraphQL SDL and local introspection JSON examples.
- `configs/`: scan configuration examples.
- `evaluation/`: ground-truth examples.
- `benchmarks/`: benchmark configuration examples.
- `labs/`: local lab pack examples.
- `auth/`: authentication profile notes.

Examples are intentionally local and use placeholder environment variable names instead of
secret values.
