# Roadmap

This page reflects the current practical roadmap, not older milestone lists in pre-development
references.

## Implemented or Being Finalized

- Authentication profiles.
- Configuration profiles.
- GraphQL discovery.
- GraphQL valid payload generation.
- GraphQL execution.
- GraphQL mutation and safe attack payload generation.
- GraphQL analysis and safe marker coverage.
- Performance, rate limiting, and scan stability.
- Documentation and user manual.

## Removed from the Core Product

- Third-party baseline comparison as a YSLFuzz feature.
- Thesis experiment runner as a YSLFuzz feature.

Those activities can be performed externally using YSLFuzz reports, CSV exports, benchmark
artifacts, and lab metadata.

## Remaining Core Milestones

- Final hardening and security review.
- Release candidate v0.1.0.

## Optional Future Work

- HTML report polishing.
- Advanced Markdown report polishing.
- CI/CD and release packaging automation.
- Advanced GraphQL support such as richer fragments or subscriptions, if safe and explicitly scoped.
- Richer authentication workflows such as token refresh, if safe and explicitly scoped.
